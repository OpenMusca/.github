# Contributing (OpenMusca organisation default)

Thanks for helping. The project rules are in the documentation: https://openmusca.github.io/contributing/ and
https://openmusca.github.io/development/. The short version:

- Small commits, one topic each, message in English: `area: what and why`.
- Run the repository's test script before opening a pull request. Tests never touch a device.
- Clean room: do not copy vendor (PETKIT, Axera, Realtek) source, headers, binaries, firmware dumps or images into any
  repository of this organisation. Describe observed behaviour and write the code from scratch.
- Never post your own addresses, serial numbers, MAC addresses, tokens or passwords in an issue or pull request;
  redact them. Security problems go through the private process in the security policy, not a public issue.
- By contributing you agree that your contribution is licensed under the licence of the repository you contribute to.
